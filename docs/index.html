What sticks from one NFL season to the next?

This analysis measures the association between an entity’s previous 1, 2, or 5 seasons and its following season. It is intentionally a transparent persistence study, not a full forecasting model.

How to read it

Every result correlates an equally weighted prior-history average with next-season performance. A larger positive correlation means the earlier performance contains more signal about the next year. The chart and table include sample size because strict five-year QB eligibility is intentionally selective.

For rank-based and outlier-resistant context, every domain page also reports Spearman correlation, 2020-excluded results, and leave-one-entity-out influence.

Consistent orientation

Higher is better in every domain. Defense is shown as EPA prevented per play, the negative of EPA allowed.
